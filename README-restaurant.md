# Restaurant website

A multi-page responsive restaurant website built with HTML and CSS.

## Pages
- `index.html` – home page
- `html/menu.html` – menu
- `html/gallery.html` – photo gallery
- `html/about.html` – about the restaurant
- `html/contact.html` – contact page

Also included: `sitemap.xml` and `xml.rss` (RSS feed) for search engines and feed readers.

## Technologies
HTML5, CSS3, Font Awesome, custom fonts.

## Run locally
No build step is needed. Clone the repo and open `index.html` in a browser.

```bash
git clone https://github.com/MinaJevtic7523/restaurant.git
cd restaurant
```
