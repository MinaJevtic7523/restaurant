# Aurora Haven – Restaurant website

A multi-page responsive website for a fictional restaurant, built as a web development portfolio project.

## Pages
- `index.html` – home page with signature dishes, specials and story teaser
- `html/menu.html` – full menu
- `html/gallery.html` – photo gallery
- `html/about.html` – story and mission
- `html/contact.html` – contact form (demo, nothing is sent) and details

Also included: `sitemap.xml`, `robots.txt` and `xml.rss` (RSS feed).

## Technologies
HTML5, CSS3 and a little vanilla JavaScript (mobile menu and form validation). No frameworks and no external dependencies, fonts and icons are local.

## Run locally
No build step is needed. Clone the repo and open `index.html` in a browser.

```bash
git clone https://github.com/MinaJevtic7523/restaurant.git
cd restaurant
```
